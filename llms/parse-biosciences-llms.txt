# Parse Biosciences

> Parse Biosciences makes Evercode, a split-pool combinatorial barcoding chemistry for single
> cell and single nuclei RNA sequencing that runs on standard lab equipment instead of a
> dedicated microfluidics instrument. Analysis is delivered through Trailmaker, a cloud
> application. Parse publishes NO public developer API, NO SDK, and NO machine-readable API
> contract.

## What an agent can and cannot do here

- There is no public API. There is no OpenAPI, AsyncAPI, GraphQL SDL, gRPC .proto, WSDL,
  MCP server, or A2A agent card on any Parse-controlled host.
- Trailmaker (https://app.trailmaker.parsebiosciences.com) is an end-user web application.
  Its backend, https://api.app.trailmaker.parsebiosciences.com, is live and answers 401 with
  {"message":"The request does not contain an authentication token."} — it is authenticated
  with AWS Cognito and is not documented or offered to third parties.
- Product selection, quoting and purchasing go through a contact form, authorized
  distributors, or a service provider. There is no pricing page and no self-serve signup.
